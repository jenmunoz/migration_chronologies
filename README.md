#For each of the areas of interest there are twotypes of plots relative abundance plots and percentage of population pots:

a) In the context of eBird, relative abundance  represents the estimated number of individuals detected by an eBirder during a traveling count conducted at the optimal time of day for each species. It is a useful metric for identifying areas with relatively higher or lower bird occurrence, although these values should not be interpreted as absolute abundance.
The values shown in the plots represent the sum of the estimated relative abundance within the selected region for each month.

b)The percent of modeled population is calculated as the sum of estimated relative abundance within the selected region divided by the sum of estimated relative abundance across the species  global distribution. These figures allow you to: compare the seasonal importance of different species within the same region, compare the same species across different regions. For some of the hunting districts, percentage population plots are still being processed, as certain species take longer to run, but most of them are there.
